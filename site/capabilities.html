What ships

Capabilities of the shared core

pirs and pirs-claw share one Rust agent core. Hard gates and tools stay in Rust; team taste and policies live in Rhai packs.

Agent & multi-model

Streaming agent loop

OpenAI-compatible and Anthropic providers with tool calling, retries, thinking blocks, auto-compaction.

Multi-backend models

OpenRouter, DashScope, DeepSeek, OpenAI, Anthropic, Groq — pin backend/id or portable names with failover.

Strategies & hybrid

Multi-phase policies; weak-drive hybrid thrash→advisor. Role-split usage when models differ. Details →

Rhai programmable

Custom tools, hooks, slash commands, profiles, strategy overrides. Details →

Delegation & cascade

delegate with per-subagent model; --cascade draft-then-escalate; spawn_subagent from packs.

Background jobs

bash/delegate with background: true; manage via jobs / job_output / job_kill / job_steer.

Code intelligence

Code graph

Tree-sitter index (Rust/Python/TS/Go): code_map definitions, callers/callees, top, blast radius.

LSP

Definition, refs, hover, symbols, workspace search, implementations, type def, call hierarchy, diagnostics; rename_symbol.

AST edits

ast_edit: list functions, replace body, insert before/after, rename, move — multi-lang with parse rollback.

Search & map

Hybrid code search, repo map, project toolchain profile (detect packages, pre-commit-style checks).

Safety, audit & control

Approvals & profiles

--approval auto/ask/yolo; agent profiles plan / accept-edits / auto-approve at the tool gate.

Native audit

~/.pirs/audit.jsonl, audit_tail, secret-key redaction; disable with PIRS_AUDIT=0.

Undo & checkpoints

/undo, session_rewind, per-turn snapshots; optional stash/file checkpoint packs.

Sandbox & guards

OS sandbox pack for bash; path/mutation guards; Rust hard denials packs cannot loosen.

Worktrees

--worktree NAME → isolated .pirs/worktrees/<name>.

Doctor

pirs --doctor and tool doctor for environment honesty probes.

Interfaces

TUI

Ratatui console: tour, slash completion, tool groups, approvals, steer-by-typing, images, voice foothold.

Web UI

pirs --serve / --mode web — browser SPA with full tools/packs/MCP.

RPC & ACP

Headless JSONL RPC; Agent Client Protocol for editors (images + fs read/write).

Multi-root cwd

--cwd + --also for multi-repo work context (//root/… paths).

Ops, browse & documents

PR & fleet

Tool pr (status/diff/create/checks via gh); fleet + pirs-orchestrator.

Research

Multi-page digest tool → .pirs/research/.

Browser CDP

Multi-page open/list/switch, click/type; computer-use when enabled.

Office documents

Read extracts docx/pptx/xlsx/pdf; office_document creates/updates OOXML.

MCP connectors

Email/calendar and more via .mcp.json / ~/.pirs/mcp.json — not in-process OAuth clients.

Skills & learn

Progressive skills, skill_view, crystallize successful runs into SKILL.md.

Session tools (built-in)

ask_user todo goal pack read / write / edit bash grep / code_search trace / flight recorder

Personal agent (pirs-claw)

  • Telegram-first gateway with pairing allowlist (fail closed)
  • Schedules: fire, fail, timeout
  • Exec local / docker / ssh
  • Same coding tools, skills, and learn stack as the harness
  • Other channels (Discord/Slack/…) are thin stubs — not production depth
