Examples

Start with the dual-model fix, then TUI, then a custom tool if you need one.

Fix failing tests (two models)

cd your-project

pirs --model deepseek-v4-flash --plan-model deepseek-v4-pro \
  --strategy weak-drive "fix the failing tests"

Interactive terminal UI

pirs --mode tui
# type a task, or press 1/2/3 on first run for starters
# type / then Tab for commands

Unattended run (CI / overnight)

By default the agent can’t run shell without a looser autonomy setting:

pirs -C /path/to/project --autonomy full \
  --model deepseek-v4-flash --plan-model deepseek-v4-pro \
  --strategy weak-drive "fix the failing tests"

Browser UI

pirs --serve
# open the URL it prints

Add a custom tool

.pirs/extensions/word_count.rhai:

register_tool("word_count", "Count words", #{
    type: "object",
    properties: #{ text: #{ type: "string" } },
    required: ["text"]
});

fn tool_word_count(args) {
    `${args.text.split(" ").len()} words`
}

Simple plan → code strategy

.pirs/strategies/my-plan.rhai, then --strategy my-plan:

#{
    name: "my-plan",
    phases: [
        #{
            scope: "readonly",
            system: "You plan only. Do not edit files.",
            prompt: "Plan a fix.\n\n## Issue\n{issue}\n\n## Tests\n{targets}",
        },
        #{
            scope: "full",
            system: "Execute the plan. Run tests.",
            prompt: "Issue:\n{issue}\n\nPlan:\n{prev}\n\nImplement now.",
        },
    ],
}
