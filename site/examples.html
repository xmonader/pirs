Hands-on

Examples you can paste

CLI recipes and Rhai snippets. For the full programming model see Rhai and strategies.

CLI · day-to-day coding

Dual-model weak-drive (recommended)

Strong plan + review, weak exec · best process score on shrimpswe (4/5)

cd your-repo   # or: pirs -C /path/to/repo …

pirs --model deepseek-v4-flash --plan-model deepseek-v4-pro \
  --strategy weak-drive "fix the failing tests"

Classic plan → exec

pirs --model deepseek-v4-flash --plan-model deepseek-v4-pro \
  --strategy plan-exec "add retry with exponential backoff to the client"

Interactive TUI

pirs --mode tui
# empty input: 1 / 2 / 3 for starters · type / then Tab · ? for keys · /tour

Unattended / benches

Default autonomy edit blocks bash — use full for shell+tests

pirs -C /path/to/ws --autonomy full \
  --model deepseek-v4-flash --plan-model deepseek-v4-pro \
  --strategy weak-drive "…"

CLI · models & backends

Pin a backend / portable name

# keys in ~/.pirs/secrets.env or environment
pirs backends
pirs models search deepseek

pirs --model dashscope/qwen3.5-plus "…"
pirs --model qwen-plus --plan-model openrouter/anthropic/claude-sonnet-4 \
  --strategy plan-exec "fix the failing test"

Weak runtime flags

Tool-diet, sequential tools, more retries, default plan-exec one-shot

pirs --weak --plan-model deepseek-v4-pro "refactor the parser"

Multi-repo work context

pirs --cwd ~/code/frontend --also ~/code/backend --mode tui
# paths: //backend/src/…  or relative (tries each root)

Browser UI

pirs --serve
# or: pirs --mode web

Rhai · custom tool

Save as .pirs/extensions/word_count.rhai:

Tool the model can call

Use backtick strings for ${…} interpolation

register_tool("word_count", "Count words", #{
    type: "object",
    properties: #{ text: #{ type: "string" } },
    required: ["text"]
});

fn tool_word_count(args) {
    `${args.text.split(" ").len()} words`
}

Rhai · policy hook

Block patterns before tools run

Packs can only add denials — Rust hard denials still apply

fn on_tool_call(id, name, args) {
    if name == "bash" && args.command.contains("rm -rf") {
        return #{ block: true, reason: "rejected by policy" };
    }
    if name == "bash" && args.command.contains("git push --force") {
        return #{ block: true, reason: "no force-push" };
    }
    ()
}

Rhai · two-phase strategy

Save as .pirs/strategies/my-plan.rhai, then --strategy my-plan:

Readonly plan → full exec

#{
    name: "my-plan",
    phases: [
        #{
            scope: "readonly",
            system: "You plan only. Investigate; do not edit.",
            prompt: "Plan a fix.\n\n## Issue\n{issue}\n\n## Tests\n{targets}",
        },
        #{
            scope: "full",
            system: "Execute the approved plan. Verify with tests.",
            prompt: "Issue:\n{issue}\n\nPlan:\n{prev}\n\nImplement and verify.",
        },
    ],
}
