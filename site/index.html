pirs is a multi-model coding agent harness you can extend with Rhai scripts — custom tools, lifecycle hooks, slash commands, and multi-phase strategies. Plan on a strong model, execute on a cheap one.

.pirs/extensions/policy.rhai 
register_tool("word_count", "Count words", #{
    type: "object",
    properties: #{ text: #{ type: "string" } },
    required: ["text"]
});

fn tool_word_count(args) {
    `${args.text.split(" ").len()} words`
}

fn on_tool_call(id, name, args) {
    if name == "bash" && args.command.contains("rm -rf") {
        return #{ block: true, reason: "rejected by policy" };
    }
    ()
}

Install

Build from source or grab a release

Quick install script

curl -fsSL https://raw.githubusercontent.com/xmonader/pirs/main/scripts/install.sh | sh

Installs pirs, pirs-claw, pirs-orchestrator into ~/.local/bin.

From source

git clone https://github.com/xmonader/pirs.git
cd pirs && cargo build --release
export OPENAI_API_KEY=…   # or provider keys
./target/release/pirs --mode tui

Recommended coding recipe

pirs --model deepseek-v4-flash --plan-model deepseek-v4-pro \
  --strategy weak-drive "fix the failing tests"

More recipes on the examples page. Keys: env or ~/.pirs/secrets.env.
