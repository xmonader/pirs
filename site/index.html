Strategies

Policy in Rhai. Mechanism in Rust.

Built-in strategies are embedded maps — project files under .pirs/strategies/ shadow the same name.

Name Shape Multi-model
monolithic One growing loop --model only
plan-exec Readonly plan → full exec Plan on --plan-model
plan-critic-exec Plan → critic → exec Plan/critic on plan-model
spark-ember Parallel spark explore → ember code Spark ↔ plan, ember ↔ model
weak-drive Strong plan → weak exec → strong review → weak fixup hybrid thrash→advisor
Recommended day-to-day: dual-model weak-drive or plan-exec. Use --autonomy full for unattended / bench runs (default edit blocks bash).

Install

Build from source or grab a release

Quick install script

curl -fsSL https://raw.githubusercontent.com/xmonader/pirs/main/scripts/install.sh | sh

Installs pirs, pirs-claw, pirs-orchestrator into ~/.local/bin (override with PIRS_INSTALL_DIR).

From source

git clone https://github.com/xmonader/pirs.git
cd pirs
cargo build --release

export OPENAI_API_KEY=…   # or Anthropic / provider keys
./target/release/pirs --mode tui

Recommended coding recipe

pirs --model deepseek-v4-flash --plan-model deepseek-v4-pro \
  --strategy weak-drive "fix the failing tests"

# Unattended / benches — shell must work
pirs -C /path/to/ws --autonomy full \
  --model deepseek-v4-flash --plan-model deepseek-v4-pro \
  --strategy weak-drive "…"

Keys: env or ~/.pirs/secrets.env. Never commit secrets.
