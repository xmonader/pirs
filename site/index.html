Open source · alpha

A coding agent you can program.

pirs sits in your terminal (or browser), reads the repo, edits code, and runs tests — like other coding agents. The difference: you can change how it behaves with short scripts, and you can pair a cheap model for doing work with a strong model for planning.

Try it Source on GitHub
typical run 
$ pirs --model deepseek-v4-flash \
    --plan-model deepseek-v4-pro \
    --strategy weak-drive \
    "fix the failing tests"

# 1. strong model writes a plan
# 2. cheap model edits code
# 3. strong model reviews
# 4. cheap model fixes if needed

✓ tests pass

Three things to know

It can use two models

One for thinking through the task, one for typing code. That keeps cost down without giving up quality on hard steps.

How strategies work →

You can script it

Add your own tools, block unsafe commands, or change the step-by-step workflow — with small Rhai scripts, no rebuild.

pirs

The coding agent. Point it at a repo and give it a task. TUI, web UI, or one-shot from the CLI.

pirs-claw

Get started

1. Install

curl -fsSL https://raw.githubusercontent.com/xmonader/pirs/main/scripts/install.sh | sh

# or from source
git clone https://github.com/xmonader/pirs.git
cd pirs && cargo build --release

2. Add an API key

# any OpenAI-compatible or Anthropic key works
export OPENAI_API_KEY=…
# or put keys in ~/.pirs/secrets.env

3. Run it on a repo

cd your-project
pirs --mode tui

# or one-shot with two models (recommended for real bugs)
pirs --model deepseek-v4-flash --plan-model deepseek-v4-pro \
  --strategy weak-drive "fix the failing tests"

More copy-paste recipes on the examples page. Unattended runs need --autonomy full so the agent can run shell commands.

Does it work?

On the same strict 50-bug SWE-bench Lite set (agent never sees the test patch): weak-drive 34/50, no-strategy 31/50, monolithic 29/50 (flash executor; weak-drive also uses pro for plan/review). On a 5-task process suite: weak-drive and plan-exec 4/5, mono/naive 3/5. Full table and caveats on the strategies page.
