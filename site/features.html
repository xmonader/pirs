What ships

Features

Coding depth first. Personal Telegram agent second. No channel zoo — by design.

Coding

  • Read, search, and edit files in your project
  • Run shell commands and tests
  • Work with git and open PRs (via gh when available)
  • Understand structure better than grep alone (code map, LSP when you have a language server)

Models

  • Works with OpenAI-compatible APIs and Anthropic
  • Built-in support for common providers (OpenRouter, DeepSeek, DashScope, Groq, …)
  • Use one model for everything, or a strong + cheap pair — see strategies

How you talk to it

  • Terminal UI — pirs --mode tui
  • Plain REPL — default interactive mode
  • Browser — pirs --serve
  • One-shot CLI — pirs "do the thing"
  • Editors — Agent Client Protocol (ACP)
  • Telegram — via pirs-claw

Safety & control

  • Ask before risky tools, or run more open for unattended jobs
  • Session undo and an audit log of what happened
  • Optional sandbox and guard packs for shell commands
  • Scripts can block commands; core hard limits can’t be turned off by packs

Customization

  • Add tools and policies with Rhai scripts — extend
  • Dozens of optional packs ship in the binary (goals, review, thrash guards, …)
  • MCP connectors for things like email/calendar when you configure them

Also useful

  • Multi-repo workspaces (--cwd + --also)
  • Background jobs and multi-agent fleet tooling
  • Browser automation and office document helpers
  • Honest bench harness for judging real fixes (pirs-bench)

Deeper product notes: docs/PRODUCTS.md
