Multi-phase policies

Strategies shape the agent loop

Strategies are policy, not mechanism. Built-ins are Rhai maps embedded in the binary; put .pirs/strategies/<name>.rhai in a project to override the same name.

Catalog

Name Aliases Shape Multi-model
monolithic — One growing loop --model only
plan-exec — Readonly plan → full exec Plan on --plan-model
plan-critic-exec plan-exec-critic Plan → critic → exec Plan/critic on plan-model
spark-ember dual, soul-dual Parallel spark explore → ember code Spark ↔ plan, ember ↔ model
weak-drive advisor, weak-strong, advise-exec Strong plan → weak exec → strong review → weak fixup hybrid thrash→advisor
wide-plan-exec — Wide / fan plan variants Secondary
plan-exec-weak — Weak-oriented plan-exec Secondary
Day-to-day default: weak-drive or plan-exec with dual models. Pair with --autonomy full for unattended runs (default edit blocks bash).

weak-drive in depth

Agentpy-style hybrid as a first-class strategy: cheap model drives tools; strong model at scheduled plan/review checkpoints — and mid-loop when thrash fires (product path, when hybrid: true and --plan-model are set).

0

Strong plan · readonly

--plan-model writes a self-contained plan for a weaker executor. No edits.

1

Weak exec · full tools

--model implements the plan. Hybrid thrash→advisor + ask_advisor when hybrid is on.

2

Strong review · readonly

Sees original plan via {prev_0} and exec summary via {prev}. Outputs APPROVE or REVISE.

3

Weak fixup · full tools

skip_if_prev_prefix: "APPROVE" — free skip when review approved. Otherwise apply recovery plan.

pirs --model deepseek-v4-flash --plan-model deepseek-v4-pro \
  --strategy weak-drive "fix the failing tests"

How strategies load

  1. .pirs/strategies/<name>.rhai (project)
  2. ~/.pirs/strategies/<name>.rhai (user)
  3. Built-in embedded script (same stem)

Aliases normalize before lookup (e.g. advisor → weak-drive). Built-ins are parse-checked in unit tests — a bad shipped script fails CI-style tests.

CLI shapes

Monolithic baseline

pirs --model deepseek-v4-flash --strategy monolithic "…"

Classic plan → exec

pirs --model deepseek-v4-flash --plan-model deepseek-v4-pro \
  --strategy plan-exec "…"

Verify loop (re-plan on gate fail)

pirs --model … --plan-model … --strategy plan-exec \
  --verify "pytest -q" --max-attempts 3 "…"

Weak runtime composition

Tool-diet, sequential, retries ≥ 3, default plan-exec one-shot

pirs --weak --plan-model deepseek-v4-pro "…"
