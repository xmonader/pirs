How the agent works a task

Strategies

A strategy is just the step-by-step playbook pirs follows for a task. Pick one with --strategy …. You can also write your own as a script.

Start here

★

weak-drive — best default for real bugs

Strong model plans → cheap model codes → strong model reviews → cheap model fixes if needed. Use two models: --model (cheap) and --plan-model (strong).

2

plan-exec — simple two-step

Plan once, then execute. Good when you want dual models without the full review loop.

3

monolithic — one model, one loop

Classic single conversation. Fine for small tasks or when you only have one model set up.

pirs --model deepseek-v4-flash --plan-model deepseek-v4-pro \
  --strategy weak-drive "fix the failing tests"

What weak-drive does

  1. Plan — strong model reads the code and writes a concrete plan (no edits).
  2. Execute — cheap model makes the changes and runs tests.
  3. Review — strong model says approve or revise.
  4. Fix up — if revise, cheap model applies the recovery plan. If approve, this step is skipped.

If the cheap model gets stuck mid-task, it can also ask the strong model for help (when hybrid mode is on — the default for this strategy).

Also available

  • plan-critic-exec — plan, then a critic pass, then execute
  • spark-ember — explore in parallel, then code

Full names, aliases, and script format: docs/STRATEGIES.md

Write your own

Strategies are plain scripts under .pirs/strategies/. See a minimal plan→exec example on the examples page, or the built-ins in crates/pirs-rhai/builtins.
